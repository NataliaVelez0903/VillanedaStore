## Cómo ejecutar

Desde la raíz del repositorio:

```powershell
cd Villaneda-store
npm ci
npm start
```

Abrir http://localhost:4200.

Para comprobar la compilación, desde la carpeta de Angular:

```powershell
npm run build
```

## 

Las siguientes ubicaciones están dentro de `Villaneda-store/src`.

| Elemento | Ubicación |
|---|---|
| Colores y estilos globales | `styles.css` |
| Encabezado inicial reutilizable | `app/layout/navbar` |
| Rutas y redirección a Inicio | `app/app.routes.ts` |
| Páginas provisionales | `app/paginas` |
| Página para direcciones inexistentes | `app/paginas/pagina-no-encontrada` |
| Modelo compartido de productos | `app/compartido/modelos/producto.ts` |
